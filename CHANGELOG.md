# Change Log

All notable changes to the "1984" theme extension will be documented in this file.

## [0.3.5] - 2026-01-23

### Added
- TypeScript/TSX support: interface, type, enum, namespace keywords and type annotations
- Rust support: lifetimes, macros, self/super keywords, traits, structs, enums, primitives, attributes
- React/JSX support: component tags, expression braces
- Go package name highlighting
- JSON, YAML, TOML property key highlighting
- Decorator support for TypeScript and Python
- Type parameter/generics highlighting
- MIT License file

### Fixed
- Search highlighting now visible in comments (added `editor.findMatchBackground` colors)
- Updated Twitter link to X in README
